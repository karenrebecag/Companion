- **El chat ya no descarga imágenes por orden del modelo (2026-10-19).** Un bloque `companion:gallery` en la ventana de chat cargaba al instante cualquier URL https que el modelo escribiera, sin que hicieras clic; una instrucción inyectada en una página podía así sacar datos en la dirección de la imagen. Ahora el chat lo muestra como código, igual que la isla.
- **Leer páginas ya no llega a tu red local (2026-10-19).** `web_fetch` y `read_url` solo aceptan https hacia sitios públicos: se rechazan localhost, direcciones privadas, de enlace local y CGNAT, y `.local`. Cada redirección se revisa con la misma regla y se corta si apunta hacia adentro. Queda fuera una limitación: un nombre público que resuelva a una dirección privada (DNS rebinding) todavía pasa.
